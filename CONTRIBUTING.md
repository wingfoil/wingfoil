# Contributing to WingFoil

WingFoil takes contributions as **Memory elements**, not as an inbox of pull requests: you file the
defect or the decision, and an AI agent carries it through the review gates into delivered work.
The full model, and how you are credited for the work derived from your contribution, is in
**[`COLLABORATION.md`](COLLABORATION.md)** (decision: `dl-020-contribution-model`).

In short:

- **A defect:** open an issue with the **Bug report** form. Its fields are the `bug` element's, so it
  is captured as one without asking you again.
- **A proposal** about the product or the process: open an issue with the **Proposal** form, which is
  captured as a `decision-log`.
- **A question:** ask in [Discussions](https://github.com/wingfoil/wingfoil/discussions/categories/q-a),
  not in the issue tracker.
- **A vulnerability:** never in a public issue. Follow [`SECURITY.md`](SECURITY.md).
- **A pull request:** its template asks for the Memory element the change implements.

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
