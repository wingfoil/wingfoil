## Description

`bug-360` (medium, REQ-SEC-06): `..` segments in a type's `path` let `memory add` write outside the repository.
`bug-216`: memory.yaml `id_pattern` is not validated by `idPatternIssues` (spec-009 Pass 2). `bug-262`: `memory history`
reads past statuses without checking the document's `format`.

- (red-first) A memory.yaml `id_pattern` that `idPatternIssues` rejects fails to load (spec-009 Pass 2), as a workflow's does.
- (red-first) `memory history` reports a past revision whose `format` is unsupported as unreadable (the channel task-257 added for current documents), not as a status.
