## Description

patch never runs a retrospective (`dl-092` Q2 (ii)), so v0.3.2's release-health would read `RH-v0.3.1-01..03` as
"not adopted". Ruling (release-planning v0.3.2 R8): only the `pending` label for a patch's proposals; how a minor
settles them later stays with `dl-167`.
