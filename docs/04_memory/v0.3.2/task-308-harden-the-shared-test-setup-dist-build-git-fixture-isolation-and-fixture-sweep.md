## Description

The test infrastructure every suite and every parallel task worktree goes through. `bug-336`: an interrupted jest can
leave `dist/` missing (`test/dist-lock.cjs` removes it before building). `bug-066`: a root-owned `dist/` gives a raw
EACCES. `bug-278`: the git fixture reads the developer's global git config. `bug-208`: fixture directories of killed
jest runs are neither counted nor removed. Rulings (R8): `bug-336` builds in a temporary directory and renames it into
`dist/` atomically; `bug-208` counts and sweeps the tags of dead pids only (no fail policy, no legacy prefixes);
`bug-066` the diagnostic half only.

## Acceptance Criteria

- (red-first) `prepareDist` builds into a temporary directory and renames it into `dist/`; an interrupted build leaves the previous `dist/` intact (a test simulates the interruption).
- (red-first) A `dist/` that cannot be removed or replaced (EACCES) fails global setup with a message naming the path and the cause, not a raw stack.
- (red-first) `test/storage/helpers/git-fixture.ts` runs git isolated from the global config (`GIT_CONFIG_GLOBAL` / `GIT_CONFIG_NOSYSTEM`); a test with a global `excludesFile` shows the fixture is unaffected; its comment is true.
- (red-first) `test/global-teardown.cjs` counts and removes the fixture directories whose tag names a pid no longer alive, and leaves live ones.
- (characterization) The full suite passes twice in a row under `--maxWorkers=2`.
