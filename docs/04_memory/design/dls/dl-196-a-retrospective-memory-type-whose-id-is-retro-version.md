## Context

`retrospective.yaml`'s `capture` runs `memory.add(type: decision-log, title: "Retrospective {release.version}")`, which allocates `dl-<n>-retrospective-v…` (`id_pattern: dl-{n}-{slug}`), while its `produces:` and `compare.cjs` expect `retro-{version}`; `retro-v0.1`, `retro-v0.2` and `retro-v0.3` were all created by hand under that id (`bug-362`, `triaged`, v0.4). ## Decision

Options:
