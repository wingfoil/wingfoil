## Context

The CLI has no verb to read a type's resolved definition, one element's full content, or a directive's body (the MCP server serves some of them as Resources), and no `memory validate` to check an element before `submit`: `wingfoil memory show x` → `error: unknown command 'show'`; `wingfoil memory --help` lists no validate (0.3.0 code build, 2026-10-21).

## Decision

Options: **(a)** `memory show <id>`, `memory types [<type>]`, `directive show <id>` and `memory validate <id|path>` (submit's checks, no commit); **(b)** only `memory validate`; **(c)** no change: the MCP Resources are the read path.

Recommendation: (a), mirroring the Resources so CLI-only agents (see `KR-RP-F5`'s decision) read the same.

## Rationale

CLI-only agents and scripts cannot read what MCP clients read; a dry check before submit avoids a refused transition.
