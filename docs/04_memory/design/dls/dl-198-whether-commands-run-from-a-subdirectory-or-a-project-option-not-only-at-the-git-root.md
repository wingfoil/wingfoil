## Context

Every command, read-only ones included, refuses to run outside the repository root: from a subdirectory `wingfoil workflow list` → `error: E_NOT_AT_GIT_ROOT: run wingfoil from the project root`, exit 1 (0.3.0 code build, 2026-10-21).

## Decision

Options: **(a)** a global `--project <dir>` option; **(b)** read-only commands resolve the root upwards, mutating ones keep the refusal; **(c)** no change, with the rationale documented in the user guide.

Recommendation: (a) plus (c)'s documentation.

## Rationale

Tools that drive WingFoil from elsewhere need an explicit root; inferring it for writes would weaken the determinism rule of declared configuration.
