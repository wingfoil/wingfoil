## Context

**The workflow format cannot say which method a phase follows.** Templates (svc-018 F-016, seen on 0.2.2, unfiled
since the v0.3 retrospective restated it) compared the phases of the governed repositories: the method a phase
follows (Lean Inception, User Story Mapping, BDD, TDD, Kanban, or a house practice) appears only in comments and
descriptions, so a phase that follows none goes unnoticed. In this repository no workflow file declares one
(`grep -rn -iE '^\s*method:' .wingfoil/workflows/custom` → nothing).

**Unknown keys are kept and ignored today.** The phase schema is `.passthrough()` (`src/workflow/schema.ts`, per
`spec-009` §2), so a `method:` key added by hand loads and is read by nothing.

**`dl-149` sets the bump rule**: an additive, optional field does not bump a file kind's `format`.

## Decision

Options:
- **(a) An optional `method` key on a phase and on a workflow:** `method: { kind: methodology | standard | house,
  ref: "<name and section>" }`. `house` states that no external method applies; `standard` covers mechanical phases
  (SemVer, Keep a Changelog). `workflow show` prints it; `workflow next` prints it with the step. The rule that comes
  with it, written into the `determinism` directive: **the label never replaces the steps** — every practice the
  method requires is declared as phases, checks, `produces` or Memory templates, because a bare reference leaves the
  method's content to each agent's own knowledge.
- **(b) A convention only:** name the method in `description`, with the same rule.
- **(c) No change.**

**Recommendation: (a).** Additive and optional (no `format` bump, `dl-149`), it makes a phase without a method
visible, and it gives a later check a field to compare a pack against the method it claims. (b) leaves it to prose
no tool reads.

## Rationale

- **Traceability of the process, not only of the product.** A phase that claims Kanban replenishment can be checked
  for an ordered backlog; one that claims nothing can be flagged.
- **Determinism is protected by the rule, not by the key.** The key alone could increase variance between runs
  (each agent fills the method in from memory); the rule keeps the definition in the configuration.
