## Context

`git-conventions` §7 asks every commit an agent writes (except approve/reject) to end with `Co-Authored-By:` and `AI-Model:`. The commits the mutating verbs write carry only `WingFoil-Version:` (and the workflow trailers): `node dist/cli.js memory add --type plan … --dry-run` prints a message whose only trailer is `WingFoil-Version`. So every tool-written commit of v0.3 made by an agent was amended by hand (at least 14 ingest plans, W2 B1–W3 B9). `agent execute` hands the rule to the agents it launches; an agent started by itself has only the project's agent file.

## Decision

Options:

- **(a)** The verbs accept the attribution from the environment (for example a variable `agent execute` sets, naming a `team.agents` entry) and write the two trailers themselves;
- **(b)** a `--co-author <team.agents name>` option on every mutating verb;
- **(c)** no change: the agent amends, as today.

Recommendation: (a), with (b) as the explicit override.

## Rationale

A rule every agent must apply by hand to the tool's own output is the costliest kind; the tool knows the act and can read the identity.

## Actions

- At v0.4 planning, beside `dl-180` (the bootstrap), `dl-169` (team.agents as authors) and `dl-137` part (b): rule.
