## Context

The release-health catalogue (`docs/08_health/metrics.yaml`, version 2, `task-222`) defines **G07 "Unknown
identities"**: "Commits whose author or committer is not a `team.members` entry of `dna.yaml` at the measurement
point, or uses an RFC 2606 reserved domain", a floor metric with `floor: 0`.

Agents are declared under `team.agents`, not `team.members` (`dna.yaml`, `team.agents`: `name: Claude`, `email:
noreply@anthropic.com`, `approval_authority: false`). Today they appear only as `Co-Authored-By:` trailers
(`git-conventions` §7); the author and committer of every commit is a member. When `agent execute` (`spec-016`,
`task-228`) authors commits itself — the run record, and in v1.0 a headless agent's own work — the author or committer
may be the agent entry, and G07 as written would count every such commit as an unknown identity.

`task-222`'s developer asked whether G07 accepts `team.agents` (W3 B4 follow-up log: "APPROVER Q: G07 accept
team.agents as author/committer when agent execute authors commits? (dl-089 wording kept)"). The approver ruled on
2026-10-10 (W3 B4 rulings, item 6): G07 keeps `team.members` only for now, to be revisited when `agent execute`
authors commits. This decision-log holds that revisit.

## Decision

**Q1 — which entries G07 accepts as authors and committers:**
- **(a) members only** (today's text): an agent never authors or commits; `agent execute` commits under the member who
  launched it, and the agent appears as a co-author.
- **(b) members as authors and committers, agents as authors only**: an agent-authored commit is accepted when its
  committer is a member, so a human is still accountable for what lands.
- **(c) members and agents alike**: any declared identity is known.

**Recommendation: (b), when `agent execute` first authors a commit.** It keeps accountability with a member (the
committer), matches `dna.yaml`'s `approval_authority: false` for agents, and stops G07 from flagging the declared
agent. (a) contradicts `dl-094` (one author identity per act) once the agent is the actor; (c) lets an agent commit
with no human in the loop.

## Rationale

- G07 is a floor at 0: a definition that flags every agent-authored commit makes the metric useless the day the
  feature ships.
- Until then the approver's ruling stands, so this decision-log waits: it is ratified when the task that makes
  `agent execute` author commits is planned.

## Actions

2. Under (b) or (c): G07's definition in `docs/08_health/metrics.yaml` (redefined, per the catalogue's rules) and the
