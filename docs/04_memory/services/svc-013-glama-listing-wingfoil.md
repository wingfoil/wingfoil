## Management

- **Updates:** Glama rebuilds from the repository; if the build steps or the server's command change
  (e.g. Tools with P5.2.3 in v0.4, or a change to `wingfoil mcp`), update Admin → Dockerfile and record it
  here. A change of maintainer is a change to `glama.json` followed by a new claim.
- **Releases:** Glama's quality checks look at GitHub Releases; `dl-130` step 1 creates them from v0.3 on.
- **Retirement:** `memory deprecate`, with a `Reason:` that says whether the listing was removed or
  replaced.
