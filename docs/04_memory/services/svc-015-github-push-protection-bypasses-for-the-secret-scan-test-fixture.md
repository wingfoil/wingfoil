rewritten (`dl-035`). Since `task-182`, no new commit carries a secret-shaped literal under `test/` (the
"dl-122 S1" suite test), so no new bypass should be needed. Retire with `memory deprecate` only if the history
that carries the literal stops being pushed anywhere.
