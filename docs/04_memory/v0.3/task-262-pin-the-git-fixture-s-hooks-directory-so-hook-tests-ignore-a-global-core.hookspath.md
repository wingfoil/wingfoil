## Description

Closes `bug-273`: five `test/core` suites plant `<repo>/.git/hooks/pre-commit` in a fixture repository from
`makeTempGitRepo` (`test/storage/helpers/git-fixture.ts`), which sets the identity, `commit.gpgsign` and `gc.auto`
locally but not `core.hooksPath`. On a machine whose global git config sets `core.hooksPath`, git never runs the
planted hook and ten tests fail.

  `.git/hooks`; a test pins it.
- (characterization) `makeTempGitRepo` and `cloneTempRepo` set `core.hooksPath` to `.git/hooks` locally; the five
  hook suites pass under a global `core.hooksPath`.
