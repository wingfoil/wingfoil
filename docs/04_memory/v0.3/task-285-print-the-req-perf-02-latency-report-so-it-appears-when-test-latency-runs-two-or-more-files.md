## Description

`npm run test:latency` with `WINGFOIL_LATENCY_REPORT=1` is where release-health reads REQ-PERF-02 (catalogue Q12,
`parseLatencyReport` in `scripts/release-health/measure.cjs`). The REQ-PERF-02 suite (`test/cli/command-latency.test.ts`)
prints its report (the load window, the `machine:` idle verdict, the floor and each command's marginal and total p95)
with `console.log` in its `afterAll`, and that output never reaches the log when the pass runs two or more test files,
as it does: three since `task-283`, two before it (`bug-378`). Both `test:latency` logs of the W3 B8 gate on `e9c71f1a`
carry the two `workflow next` lines (printed with `process.stdout.write`) and no report, so Q12 would come out
`not-measurable` at the v0.3 release-health. This task makes the report print in the pass as configured, and pins it.
