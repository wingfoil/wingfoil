## Description

`dl-146` (`ready`, ratified 2026-10-05, option (C)) settles what REQ-PERF-02 bounds. Today
`test/cli/command-latency.test.ts` (`task-154`) asserts only the marginal cost of `memory search`,
`dna show` and `memory history` over the median of a `--version` floor, and reports the total (process
start included) without asserting it. The SARD's Fit Criterion says the commands "return in < 1,000 ms
(p95)", so the requirement and the test say different things (the suite's own header says so).

Under (C) both numbers are budgets, measured on an otherwise idle machine:
- the **total** (invocation to return, process start included) at 1,000 ms p95 (Q1);
- the **marginal** cost over process start at 1,000 ms p95 (Q2: the marginal budget stays at 1,000 ms).
REQ-PERF-03 (`workflow next`) follows the same rule when the command exists (Q3).
