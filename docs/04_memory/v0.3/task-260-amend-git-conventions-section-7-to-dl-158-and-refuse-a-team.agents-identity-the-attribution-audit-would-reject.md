## Description

Implements `dl-158` (ratified 2026-10-06: Rule 1 (a), Rule 2 (ii)) Actions 2 and 3, and closes `bug-261`.
`git-conventions` §7 carries two attribution rules `task-256` wrote without a ratified source: which
`team.agents` entry signs when several are declared, and what an entry without an `email` writes. `dl-158`
rules them: the signing entry is the one `agent execute` launches (resolved by its adapter, `spec-016`), a
hand session uses the entry whose `name` is the agent's own and, with no such entry, the first entry, saying so
in the commit body (Rule 1 (a)); an entry used for commits must declare an `email`, so `dl-117` Q1 (B)'s
co-authorship is never waived (Rule 2 (ii)). `bug-261`: an `AgentEntry` accepts an empty or blank `name` and
an `email` on an RFC 2606 reserved domain, an identity the attribution audit (`isValidAttribution`) rejects.
