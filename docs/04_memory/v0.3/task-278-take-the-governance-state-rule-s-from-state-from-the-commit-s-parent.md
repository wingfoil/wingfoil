## Description

Fix `bug-308`: `reconstructMemoryTransitions` (`src/memory/audit.ts`) derives a commit's `fromState` from the previous
entry of the path's `git log --follow` walk, so on non-linear history (an amend on `main` while the same task is
started on its branch, then the merge) it derives a transition the commit never made, and the governance check's
state rule fails it. `d818c0dd` is the instance on `main`. The approver ruled on 2026-10-10 (W3 B4 rulings, item 7)
that it is fixed in v0.3 before branch protection makes the check binding (`git-conventions` §9, `dl-103` §1 (C)).
