## Description

`dl-163` S3e: a custom directive `wingfoil-cli`, bound globally in `roles.yaml`, that states which WingFoil build
is used for which job in this repository and how a missing verb or a surprise of the pinned build is handled.

## Acceptance Criteria

- (characterization) `.wingfoil/directives/custom/wingfoil-cli.md` (directive frontmatter per spec-013) says:
  Memory operations use the code build (`npm run build`, then `node dist/cli.js …`) — this repository is the only
  one that can run WingFoil from its own source; the read commands and MCP use the pinned build
  (`npm run -s wingfoil -- …`, `wingfoil-released`); the verb is used where the build in use has one, otherwise the
  declared hand procedure (CLAUDE.md §5.1 `wf()` format; `dl-095` Q3 for a blocking defect); the pinned build's

  defect goes to `bug-ingest`.

  for every DNA role; `test/directives/schema.test.ts`'s pinned `roles.global` list is updated.
