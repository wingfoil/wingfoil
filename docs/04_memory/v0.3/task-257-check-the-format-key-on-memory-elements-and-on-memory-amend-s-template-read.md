## Description

Closes `bug-241` and `bug-243`: Memory element readers (search, history, the transition verbs, `memory amend`'s
template read) never check the `format` key, so an element or template written in a newer format is read with no
`dl-149` upgrade error. Approver ruling (B2 gate, task-251): elements keep the `format` their template carries.

## Acceptance Criteria

- (red-first) an element with `format: 2` is refused by the transition verbs and `memory amend` with the `dl-149`
  error (`E_INVALID_FORMAT`, file named, "upgrade WingFoil", exit 1), and reported by the tolerant scans
  (`memory search`, `memory history`) as a diagnostic naming the file, not silently read.
- (red-first) `memory amend` refuses a type whose committed template declares a newer format, as `memory add` does.
- (characterization) an absent `format` reads as 1 everywhere; `spec-001` states the element rule (pending amendment).
