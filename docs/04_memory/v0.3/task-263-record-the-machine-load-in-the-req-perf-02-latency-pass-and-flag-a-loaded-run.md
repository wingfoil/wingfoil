## Description

Closes `bug-276`: since `task-248` (`dl-146` option (C)) the SARD makes "an otherwise idle machine" part of
REQ-PERF-02's measurement conditions and `test/cli/command-latency.test.ts` asserts the total p95 as well as the
marginal, but nothing in the pass records the machine's load or checks the condition. A run started on a momentary dip
of the 1-minute load average passed with a loaded floor.
