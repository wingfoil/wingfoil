## Summary

A directive id assigned to a role in `roles.yaml` with no directive file produces a warning only on `directives list --role <that role>`; the unfiltered listing reports nothing.

## Steps to Reproduce

1. In an initialised project, add `ghost-directive` under `qa:` in `.wingfoil/roles.yaml` and commit.
2. `wingfoil directives list --format json` → `warnings: []`.
3. `wingfoil directives list --role qa --format json` → `warnings: ["directive 'ghost-directive' bound to role 'qa' has no directive file"]` (0.3.0 code build, 2026-10-21).

## Expected Behavior

The dangling binding is reported whatever the filter (and is an error wherever configuration is checked).

## Actual Behavior
