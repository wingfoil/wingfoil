# computeStateSnapshot reads every file under .wingfoil/ so it would take the git-ignored active run registry into the state dump

## Summary

`computeStateSnapshot` (`src/storage/snapshot.ts`, the direct implementation of REQ-SYS-01's fit criterion "a state dump
before and after clone is byte-identical") reads every regular file under `.wingfoil/` in full. Since `task-336`,
`agent execute` keeps its active run registry under `.wingfoil/run/` (`ACTIVE_RUNS_DIR`, `src/agent/active-runs.ts`):
one JSON entry per running launch, holding a `pid` and a `started_ms` instant, and git-ignored (`.wingfoil/.gitignore`
`/run/`). A snapshot taken while a launch runs would therefore include a file no clone has and whose bytes depend on
the process and the clock, so the dump would differ before and after a clone. The function has no production caller
today, so the defect is latent: it bites whoever gives it one.

## Expected Behavior

The state dump covers only git-backed state: `.wingfoil/` files git tracks (or, at least, not the paths
`.wingfoil/.gitignore` ignores, `/run/` among them), plus the Memory frontmatter. A dump taken while an agent runs equals
one taken in a fresh clone.

## Actual Behavior

Every file under `.wingfoil/` is read, `.wingfoil/run/**` included, so a dump taken during a launch would carry the
registry entry.
