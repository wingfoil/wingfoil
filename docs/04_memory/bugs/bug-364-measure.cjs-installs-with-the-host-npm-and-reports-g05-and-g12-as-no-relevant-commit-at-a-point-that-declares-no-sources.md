## Summary

`measure.cjs` installs the measured tree with whatever `npm` is on the host's `PATH`, not the npm of the pipeline's
pinned Node, so a point whose lockfile the host npm refuses has its whole toolchain half `not-measurable`; and at a
point with no root `.wingfoil/dna.yaml` it gives G05 and G12 the reason "no relevant commit in the window (total: 0)",
while the cause is that the point declares no `paths.sources`.

## Steps to Reproduce

On `main` at `bd55f70e`:

1. `docs/08_health/release-health-v0.1.json` (the `task-241` baseline at `5b16ab61`, `toolchain` `{node: v22.21.0,
   npm: 11.6.2}`): Q01-Q04, Q11, Q12 and Q17 are `not-measurable` with "npm ci failed (exit 1): npm error code
   EUSAGE". Reproduced here: `git archive 5b16ab61 package.json package-lock.json` into an empty directory, then
   `npm ci --ignore-scripts` under npm 11.6.2 → `npm error code EUSAGE` … `Invalid: lock file's
   @emnapi/wasi-threads@1.2.2 does not satisfy @emnapi/wasi-threads@1.2.3`. The npm of the pinned Node (`publish.yml`
   `env.NODE_VERSION` `22.12.0`, line 213; npm 10.9) was not tried.
2. `sed -n 1474,1480p scripts/release-health/measure.cjs` → `npm('install', ['ci'])` runs `command: 'npm'` with the
   host environment; nothing chooses or records which npm the pinned Node ships.
3. The same report: G05 and G12 are `not-measurable` with "no relevant commit in the window (total: 0)", while Q05,
   Q07-Q10 say "dna.yaml at the measurement point declares no paths.sources (no .wingfoil/dna.yaml there …)". G05
   (line 616) and G12 (line 667) filter the commits by `touches(c, sources)`, and `share()` (line 545) words an empty
   source list as an empty window. `release-health-v0.2.json` gives the same G05/G12 reason at `v0.2.1`.

## Expected Behavior

The toolchain half installs with the npm of the Node it measures under (or records which npm it used and why it
differs), and G05/G12 say that the point declares no `paths.sources`, as Q05 does.

## Actual Behavior

A host-npm refusal hides the toolchain half; G05 and G12 misstate their reason.
