## Summary

`release-publishing`'s `publish` phase lists `tests.passing` among its pre-checks, and `.wingfoil/workflows/bindings.yaml`
binds that token to `npm test` (shared with `dev-loop`), while the release practice runs the suite on the release commit
with `npm run test:no-identity`, which the token `tests.no-identity` already binds; the binding a future checks runner
would execute is not the run the practice records.
