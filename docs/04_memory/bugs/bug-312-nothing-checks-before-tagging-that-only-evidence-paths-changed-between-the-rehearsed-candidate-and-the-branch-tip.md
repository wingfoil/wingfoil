## Summary

`release-publishing`'s `tag` phase tags the candidate the rehearsal transcript names, not the branch tip, because
commits that only record evidence do not re-cut the candidate (`task-219` D2, approver ruling 2026-10-10); but no
check verifies that the commits between that candidate and the tip are evidence only, so a code change landed after
the rehearsal would be left out of the tag silently, or a reader could not tell it apart from evidence.

   scripts/publish-staging.cjs scripts/e2e-smoke.cjs` prints nothing, while the same pattern over
