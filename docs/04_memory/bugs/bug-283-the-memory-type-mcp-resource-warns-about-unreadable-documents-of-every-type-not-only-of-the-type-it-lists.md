## Summary

`listMemoryDocumentsByType` (`src/memory/query.ts`), behind the MCP Resource `wingfoil://memory/{type}`, scans
every Memory document, reports each one it cannot read to `onDiagnostic`, and
only then filters by the frontmatter `type:`. Since `task-195` the Resource returns those reports as its top-level
`warnings`, so a read of `memory/bug` warns about an unreadable `adr`. The CLI's `memory search --type bug`, a
different code path, prints the same warning on stderr. A client asking for one type gets warnings about documents that are not part of its answer.

## Steps to Reproduce

On `main` at `0962f85f` (`npm ci && npm run build`), in a scratch repository (`git init`, a local identity,
`node dist/cli.js init --template Scrum`, `node dist/cli.js memory add --type bug --title "a bug"`):

1. Write `docs/memory/adr/adr-001-x.md` with the frontmatter `id: adr-001-x`, `type: adr`, `title: [unclosed`.
2. `listMemoryDocumentsByType(root, memoryYaml, 'bug', { onDiagnostic })` from `dist/memory/query.js` (with
   `loadMemoryYaml` from `dist/core/loaders.js`) → `ids: ["bug-001-a-bug"]`, and one diagnostic:
   `docs/memory/adr/adr-001-x.md: unreadable frontmatter in docs/memory/adr/adr-001-x.md: unexpected end of the stream
   within a flow collection (4:1)`. The call for `'adr'` → `ids: []` and the same diagnostic.
3. `node dist/cli.js memory search --type bug` → exit 0, stderr `warning: W_MEMORY_UNREADABLE
   (docs/memory/adr/adr-001-x.md): unreadable frontmatter …`.
4. `registerMemoryResources` (`src/mcp/memory-resource.ts`) passes the same `onDiagnostic` and returns
   `withWarnings(…, diagnostics.map(formatDiagnostic))` for `memory.list`, so the Resource read carries that warning
   (read from the code; the Resource was not driven over a transport here).

## Expected Behavior

A typed read warns only about documents that could belong to the type it lists. A document whose frontmatter cannot
be read has no readable `type:`, so the fix decides by location: a file that only the other types' `path` patterns
can produce is left out of this type's warnings; a file this type's pattern could have produced is still reported.

## Actual Behavior

Every unreadable Memory document in the repository is reported on every typed read.
