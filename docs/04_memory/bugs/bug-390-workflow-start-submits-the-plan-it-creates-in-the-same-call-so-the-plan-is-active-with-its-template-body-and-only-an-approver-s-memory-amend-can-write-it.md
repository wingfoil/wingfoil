## Summary

`wingfoil workflow start` writes the plan's `add` and its `submit` in one call (`spec-017` §7.1), so
the plan is `active` with its template body before anyone can write it, and the only verb that edits
an `active` plan, `memory amend`, needs the approver role: every plan started with the command needs an
approver's amend to get a body.

## Steps to Reproduce

1. With the dev build of `main` at `89c43d36` (`npm run build`), run
   `node dist/cli.js workflow start decision-log-ingest --title "…" --set phase=<p> --set scope=<s>`.
2. Run `git log -2 --format=%B`: `wf(plan): add <id>` and `wf(plan): submit <id>`; the submit carries
   no "Carries content" line, and the plan file still holds the template's placeholder comments.
3. Write the body and run `node dist/cli.js memory amend <id> --reason "…"` with an identity that
   holds no approver role (checked in a scratch clone with `GIT_AUTHOR_*`/`GIT_COMMITTER_*` set to a
   non-member): `error: user not authorized to approve type 'plan'`, exit `1`.

## Expected Behavior

The plan's author can write its body before it is submitted, as `memory add` + `memory submit` allow
for every other element: for example `workflow start --no-submit` (the plan stays `draft`, the
author writes it and runs `memory submit`), or `workflow start --body <file>`.

## Actual Behavior

The plan is `active` with the template body. On 2026-10-18 the six plans started for `dl-186`,
`dl-187`, `dl-188`, `bug-388`, `bug-389` and `cp-002` each needed one approver's
`wf(plan): amend … [active → active]` to carry their body.

## Notes

- Workaround: start the instance by hand, `memory add --type plan --set workflow=<w> --set phase=<p>
  --set scope=<s>`, write the body, `memory submit`. The engine treats it as an instance (`spec-017`
  §3.3: the start commit is the commit that adds the plan); this bug's own plan,
  `bug-ingest-rel-v0.3-start-plan-body-plan`, was started that way, and `workflow status` lists it with
  `capture` current.
- The two-commit design is deliberate (§7.1: every started instance is endable); the fix keeps it
  and adds a way to write the body between the two.
- Found while filing `dl-186` (E5).
