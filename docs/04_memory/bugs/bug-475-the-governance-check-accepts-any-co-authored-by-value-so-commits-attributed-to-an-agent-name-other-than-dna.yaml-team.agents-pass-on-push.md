## Summary

`git-conventions` §7 requires every agent-written commit, except an `approve` or `reject`, to end with
`Co-Authored-By: <team.agents name> <<team.agents email>>` and `AI-Model: <model id>`, the values read from
`dna.yaml` `team.agents`. The governance check (`scripts/check-governance.cjs`, run in CI and by the pre-push hook)
checks only that an approval carries no such trailer; it never compares a `Co-Authored-By:` value with `team.agents`.
During v0.3.2's release phases a session wrote `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` — a string its
runtime proposed — on 21 commits pushed to `release/0.3` and `main`, and nothing flagged them. The release-health run
measured it afterwards as a G08 floor breach (RH-v0.3.2-03 in `docs/08_health/release-health-v0.3.2.md`).

## Steps to Reproduce

From the repository root on `main` (`1db90b57f`):

1. `grep -n -A3 "^    - name: Claude" .wingfoil/dna.yaml` → `name: Claude`, `email: noreply@anthropic.com`.
2. `git log --format='%(trailers:key=Co-Authored-By,valueonly)' 954138f7c^..1db90b57f | sort | uniq -c` →
   125 × `Claude <noreply@anthropic.com>` and 21 × `Claude Opus 5.5 <noreply@anthropic.com>`.
3. `grep -n "Co-Authored-By\|team.agents" scripts/check-governance.cjs` → one hit, line 67, the rule that an approval
   carries no `Co-Authored-By:`; nothing reads `team.agents`.
4. `grep -n "RH-v0.3.2-03" -A3 docs/08_health/release-health-v0.3.2.md` → the G08 finding.

## Expected Behavior

The governance check reports a commit whose `Co-Authored-By:` names an agent identity that is not a `team.agents`
entry of the `dna.yaml` at that commit (name and email both), so the pre-push hook and CI stop it before it is pushed.
A human co-author (a `team.members` entry) stays accepted.

## Actual Behavior

Any `Co-Authored-By:` value passes; the mismatch is found only by the release-health measurement, after the push.
