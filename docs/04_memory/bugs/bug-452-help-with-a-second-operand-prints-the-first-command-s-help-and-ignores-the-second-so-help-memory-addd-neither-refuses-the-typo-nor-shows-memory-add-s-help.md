## Summary

`wingfoil help <noun> <verb>` prints the help of `<noun>` and ignores the second operand: `help memory add` does not show
`memory add`'s help, and `help memory addd` does not refuse the typo.

## Steps to Reproduce

1. In a project made with `wingfoil init --template scrum`, on the code build `0.3.1 (13c01950…)`.
2. `wingfoil help memory add` → exit 0, first line `Usage: wingfoil memory [options] [command]`.
3. `wingfoil help memory addd` → exit 0, the same first line.

## Expected Behavior

`help memory add` prints `memory add`'s help, as `memory help add` does; an operand that names no subcommand (`addd`) is refused at
exit 2 with the unknown-command line and its closest-command hint, or the surplus operand is refused (spec-005 §1).

## Actual Behavior

Commander's built-in `help [command]` takes one operand; the rest is dropped and the success path prints the first command's help.
