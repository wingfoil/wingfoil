in-process, 944 ms spawned total, against the 1,000 ms budget), because each call spends tens of git spawns that
read the same objects more than once; and the opt-in latency suite times only the in-process half, while
REQ-PERF-03's fit criterion (`dl-146` Q3) bounds the spawned total too.
