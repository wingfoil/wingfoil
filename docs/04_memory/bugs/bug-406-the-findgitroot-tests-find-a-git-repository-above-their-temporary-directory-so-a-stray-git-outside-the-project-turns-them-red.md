## Summary

The git-root tests are not hermetic: they create their fixtures under the system temporary directory and the code under test walks upwards, so an unrelated empty `.git` directory in a parent of that directory makes them fail.

## Steps to Reproduce

1. Read `release-health-rel-v0.3-plan` Execution Notes (run 1): an empty `.git` directory created outside the project in the system temporary directory turned `test/storage/git-root.test.ts` red inside measure's temporary tree; run 2, after its removal, passed.
2. `grep -n tmpdir test/storage/git-root.test.ts`: the fixtures live under the system temporary directory.

## Expected Behavior

The tests do not depend on what exists above their fixture directory (for example a ceiling the walk stops at, or a fixture root the test owns).

## Actual Behavior

A stray `.git` in a parent directory changes the result of the tests.
