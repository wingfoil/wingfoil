## Summary

`CHANGELOG.md`'s 0.3.0 section "Upgrading from 0.2.x" and the user guide's §12 "Upgrading from 0.2.x" promise the list
of changes a 0.2 project must make, but two changes that make a 0.2 configuration fail on 0.3 are in neither: (1) a
required frontmatter field whose value is a list now counts as missing unless the type names it in
`template.frontmatter.lists`; (2) a phase's `produces` entry must be a path pattern, and a prose entry makes every
workflow read fail. The Benchmark consumer met both moving a 0.2 project to 0.3.1; both reproduce on 0.3.2. This is a
documentation defect: both behaviours are the declared 0.3 contract (`spec-001` § "`lists`"; the `produces` path rule
of `spec-003`).

## Steps to Reproduce

In a scratch repository (`git init`, `wingfoil init --template Kanban --no-interactive`, pinned build 0.3.2):

1. Add a required field `requirements` to the `task` type's `template.frontmatter.required` (not to `lists`), add a
   task with `memory add`, set `requirements: [REQ-X-01]` in it, commit, then `wingfoil memory submit <task-id>` →
   `error: missing required field on submit: requirements`, exit `1`.
2. Give a phase of a committed workflow a prose `produces:` entry (text with spaces), commit, then
   `wingfoil workflow list` → exit `1` with `E_PHASE_PRODUCES_NOT_A_PATH`.
3. `grep -n "Upgrading from 0.2" CHANGELOG.md docs/user-guide.md`, then read both sections: neither names
   `template.frontmatter.lists` as a requirement nor the `produces` path rule. The changelog names `lists` only as an
   addition ("an explicit `[]` on a field listed under `template.frontmatter.lists`", 0.3.0 *Added*).

## Expected Behavior

Both lists ("Upgrading from 0.2.x" in `CHANGELOG.md` and user guide §12) carry the two items, each with the error a 0.2
configuration then meets and the fix: declare in `template.frontmatter.lists` every required field whose value is a
list; replace a prose `produces` by a path pattern, or remove it.

## Actual Behavior

Neither list names them; a 0.2 project meets the two refusals with no upgrade note to point at.
