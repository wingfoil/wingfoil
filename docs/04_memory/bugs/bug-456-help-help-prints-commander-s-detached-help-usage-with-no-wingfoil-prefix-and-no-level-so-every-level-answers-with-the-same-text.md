## Summary

`wingfoil help help` and `wingfoil <noun> help help` print Commander's detached help of the built-in help command
(`Usage: help [command]` / `display help for command`): no `wingfoil` prefix and no level, so every level answers with the same text,
unlike every other help page (`Usage: wingfoil …`).

## Steps to Reproduce

1. On `task-315`'s branch (`627313d56`), the code build (`0.3.1 (627313d5…)`), in any project.
2. `wingfoil help help` → exit 0, stdout `Usage: help [command]`, a blank line, `display help for command`.
3. `wingfoil memory help help` → exit 0, the same three lines.

## Expected Behavior

The usage names the path that answered, as the other help pages do: `Usage: wingfoil help [command]` at the root,
`Usage: wingfoil memory help [command]` under `memory`, with the same description line.

## Actual Behavior

`task-315` prints the built-in's own help with `Command#outputHelp`; the built-in has no parent, so Commander renders no command path.
