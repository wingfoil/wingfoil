## Summary

Two spec-007 blocking patterns match ordinary code and prose, not secrets. `generic-api-key-assignment` matches a key
word followed by `=` and 16 or more name characters, so it flags an assignment from a function call or a constant
name (a `const token` assigned from `stopTheLineToken()`). `dotenv-style-secret-line` (case-insensitive) matches `tokens = {` and a
commented shell example. In v0.3's release-health window this gives 6 of G14's 8 blocking findings, and none of the 8
is a secret. G14 is an `immediate_bug` floor at 0, so every window that adds such a line asks for an immediate bug.
