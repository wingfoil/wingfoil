## Summary

`docs/01_vision/00_index.md` tells agents to read only the `Lx–Ly` ranges it cites, valid for the version, date and
line count its document map records, and nothing checks either against the files. The map has been repaired twice
in a week by hand (`task-141`, `task-186`), and between the two repairs it went stale again.

## Expected Behavior

A `test/docs/` check fails when a vision file's header `Version`/`Date` or line count differs from its document-map
