## Summary

`memory amend` refuses every release added before `dl-092` (`minor-v0.1`, `minor-v0.2`, `minor-v0.3`, `minor-v0.4`,
`minor-v1.0`) with `missing required field on amend: kind`, although those ids carry no `kind:` by design and
`release-planning`'s `define-scope` check exempts them from that one field.

## Steps to Reproduce

On `main` at `0da232cb`, with the code build of that commit:

1. Make any edit to a pre-`dl-092` release, e.g. append an empty line to
   `docs/04_memory/planning/rl-v1/minor-v0.4.md`.
2. `node dist/cli.js memory amend minor-v0.4 --reason "probe" --dry-run` → `error: missing required field on amend:
   kind`, exit `1`.
3. The positive case: the same edit on `patch-v0.2.2` (which carries `kind: "patch"`) and `node dist/cli.js memory
   amend patch-v0.2.2 --reason "probe" --dry-run` → a dry-run commit `wf(release): amend patch-v0.2.2 [released →
   released]`, exit `0`.

## Expected Behavior

`memory amend` applies to a release the same exemption the configuration already declares for it: the releases
added before `dl-092` are immutable ids with no `kind:` (`.wingfoil/memory.yaml:109`, the `release` `id_pattern`
comment), and `define-scope`'s check reads `frontmatter.required: [title, kind, …] except kind for [minor-v0.1,
minor-v0.2, minor-v0.3, minor-v0.4, minor-v1.0]` (`sed -n 73p .wingfoil/workflows/custom/release-planning.yaml`).
Since `memory.yaml` 3.2 a `release` is `amendable: true` (approver ruling 2026-10-12, `task-230` D3), so amending
one of these five is a supported operation.

## Actual Behavior

The amend's required-field check (`src/core/required-fields.ts:46`, `missing required field on <verb>`) applies the
type's whole `template.frontmatter.required` list with no exemption,
so the five releases can be amended only by hand. Two hand amends were needed in wave 3 batch B6 for that reason
(`4c5fec67` and `d5cb532f`, both `wf(release): amend minor-v0.3 [in-development → in-development]`), and
`release-planning`'s `define-scope` and `.wingfoil/WORKFLOW.md:309` prescribe the hand form "while `memory amend`
refuses a release with no `kind:`" (`task-277`'s D2 ruling).
