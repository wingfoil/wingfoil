## Summary

`wingfoil directive assign` takes `--directive` and a required `--role`; a directive meant for every role can only be made global by editing the `global:` list of `.wingfoil/roles.yaml` by hand.

## Steps to Reproduce

1. In an initialised project: `wingfoil directive assign --directive x --role global` → `error: unknown role 'global' (not defined in dna.yaml)` (0.3.0 code build, 2026-10-21).
2. `wingfoil directive assign --help`: no option for the global list.

## Expected Behavior

A way to assign a directive globally through the verb (for example `--global`), committing like a role assignment.

## Actual Behavior

Only a hand edit and a hand commit reach the global list.
