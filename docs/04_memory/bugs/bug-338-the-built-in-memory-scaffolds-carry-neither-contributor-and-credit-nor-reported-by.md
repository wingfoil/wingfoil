## Summary

The Memory templates `wingfoil init` writes (`src/storage/templates.ts`, `memoryTemplateMd`) carry only
`id`, `type`, `title`, `status` and `format`, so a project scaffolded by `init` has no `contributor`, `credit` or
`reported_by:` field, which `COLLABORATION.md` and `dl-163` S3c rely on for credit and provenance.

## Steps to Reproduce

On `main` at `29b8406a`:

1. `sed -n 550,563p src/storage/templates.ts` → the frontmatter `id`, `type`, `title`, `status` (plus the `plan`
   fields) and `format`.
2. `grep -c "contributor\|reported_by\|credit:" src/storage/templates.ts` → `0`; the positive case, the same
   pattern over this repository's `.wingfoil/memory/templates/bug.md`, matches all three.

## Expected Behavior

The built-in scaffolds of the types that take a contribution carry `contributor`, `credit` and
`reported_by: []`, as this repository's templates do, so credit works the same in a scaffolded project.

## Actual Behavior

As in step 2.
