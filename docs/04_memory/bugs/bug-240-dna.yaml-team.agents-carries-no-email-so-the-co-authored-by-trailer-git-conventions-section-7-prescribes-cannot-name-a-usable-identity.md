## Summary

`git-conventions` §7 (`dl-117` Q2 (c)) says the `Co-Authored-By:` trailer names the agent entry declared in
`dna.yaml` `team.agents` (its `name:`). That entry is `name: AI agent (Claude/Cursor/etc.)` and has no email: the
`AgentEntry` schema (`src/dna/schema.ts:133-145`) declares `name`, `executes_as`, `approval_authority` and
`adapter`, and `spec-002` documents the same. A `Co-Authored-By:` line is `Name <email>`; without an email the
trailer is not a usable identity (GitHub attributes co-authors by the email), and the name itself, with `/` and
parentheses, does not read as one. So the rule cannot be followed as written, and in practice it is not: every
co-authored commit on `main` names a model, none names the declared agent.

## Steps to Reproduce

On `main` at `d3724884`:

1. `grep -n -A4 '^  agents:' .wingfoil/dna.yaml` → one entry, `name: AI agent (Claude/Cursor/etc.)`,
   `executes_as`, `approval_authority: false`; no `email`.
2. `grep -n -A12 'export const AgentEntry' src/dna/schema.ts` → no `email` field.
3. `sed -n 106,117p .wingfoil/directives/custom/git-conventions.md` → §7 "Which name": the trailer names the
   `team.agents` `name:`; an `AI-Model:` trailer carries the model id.
4. `git log main --format='%(trailers:key=Co-Authored-By,valueonly)' | grep -c 'AI agent'` → `0`;
   `git log main --format='%(trailers:key=AI-Model,valueonly)' | grep -c .` → `0`;
   `git log --since=2026-10-01 main --format='%(trailers:key=Co-Authored-By,valueonly)' | sort | uniq -c` → 758
   commits name the model (`Claude Opus 5.5 <noreply@anthropic.com>`).

## Expected Behavior

The declared agent identity is complete enough to be written as a `Co-Authored-By:` trailer: `team.agents[]`
carries an email (or `spec-002` defines how the trailer's address is derived), and its `name` is a plain name.
§7 can then be followed by hand sessions and by `agent execute`'s bootstrap (approver ruling R20).

## Actual Behavior

The trailer §7 prescribes would be `Co-Authored-By: AI agent (Claude/Cursor/etc.)` with no address. Sessions
keep writing the model's own trailer, which is what §7 was ratified to replace.
