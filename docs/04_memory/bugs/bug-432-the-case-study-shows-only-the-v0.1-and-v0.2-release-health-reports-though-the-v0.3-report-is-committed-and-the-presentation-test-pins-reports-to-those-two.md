## Summary

`docs/case-study.md` takes every figure from `release-health-v0.1.json` and `release-health-v0.2.json`. It says the
committed `release-health-v0.3.json` exists and that the page "does not show its figures yet".
`test/docs/presentation.test.ts` pins `REPORTS` to the two older reports, so nothing asks for the v0.3 column. The
v0.3.1 user-docs phase removed only the false sentences (`db272a55`). The data part is still owed, and a v0.3.1
report will add to it once the v0.3.1 release-health runs.

## Steps to Reproduce

On `release/0.3` (`8e7fc43b`):

1. `ls docs/08_health/release-health-v*.json` → `release-health-v0.1.json`, `release-health-v0.2.json`,
   `release-health-v0.3.json`. `git log --oneline -1 -- docs/08_health/release-health-v0.3.json` → `1b8fdd4e
   docs(health): release-health v0.3 report — measured at v0.3.0 (cc31d7a8)`.
2. `grep -n "^const REPORTS" test/docs/presentation.test.ts` → line 277, the v0.1 and v0.2 files only.
3. `grep -n "^| id | Metric" docs/case-study.md` → the Figures table, with columns `v0.1 at 5b16ab61` and `v0.2 at
   v0.2.1 (9833e00a)`. The "Not measurable yet" table has columns `v0.1` and `v0.2`.
4. `grep -n "does not show its figures yet" docs/case-study.md` → line 167.
5. `sed -n '/^## Reproduce/,$p' docs/case-study.md` → the commands measure `--release v0.1` and `--release v0.2`
   only. `sed -n 5,8p docs/case-study.md` → the opening still reads "the first two measurements".

## Expected Behavior

The page shows every committed report:
- a v0.3 column in Figures and in "Not measurable yet", with its measurement point (`v0.3.0` at `cc31d7a8`, basis
  `published-tag`) added to the "How it was measured" table;
- "What the figures say" rewritten over the three releases;
- a v0.3 command in "Reproduce";
- the v0.3 report added to `REPORTS`, so that `test/docs/presentation.test.ts` holds the new column to the report as
  it holds the other two.

## Actual Behavior

Two columns only, as above; `REPORTS` has two entries; the closing paragraph of "Not measurable yet" names the v0.3
report as not shown.
