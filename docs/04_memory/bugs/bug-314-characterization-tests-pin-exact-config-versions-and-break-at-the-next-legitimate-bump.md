## Summary

Characterization tests that read the live configuration pin the exact `version` of the file they check, so the next
task that legitimately bumps the same file breaks them; it happened four times in W3 B4, each loosened by hand to
"at least", with no shared helper and no written convention.

## Steps to Reproduce

1. `git log --format='%h %s'` over the test files, at `main` `02800955`:
   - `test/core/dev-loop-v1-5.test.ts`: `7a96df80` "task-270 — dev-loop v1.5 suite reads roles.yaml's version as at
     least 1.5"; `9d118a7d` (`task-221`) loosened its `toBe(1.5)` and testing `"1.1"` pins (`task-221`'s
     Retrospective);
   - `test/core/retrospective-notes.test.ts`: `4faafa4c` (`task-222`) "task-213's version pin admits a later bump";
   - `test/directives/wingfoil-cli.test.ts`: `0ffb2a9d` (`task-270`, review F1) "version lower bound";
   - `test/core/dev-loop-v1-6.test.ts`: `bindings.yaml` `version: 1.3` and dev-loop `toBe(1.6)` loosened at
     `task-221`'s review fix 1, because tasks 212, 219 and 222 also bump `bindings.yaml`.
2. `grep -n "toBeGreaterThanOrEqual" test/core/dev-loop-v1-5.test.ts test/core/dev-loop-v1-6.test.ts
   test/core/retrospective-notes.test.ts test/directives/wingfoil-cli.test.ts` → six lines, each written inline
   (`toBeGreaterThanOrEqual(1.5)`, `(1.6)`, `(1.3)`, `(1.4)`, `(1.8)`); no helper is shared.
3. `grep -n -i "version" .wingfoil/directives/custom/testing.md` prints two lines: the directive's own `version: "1.2"`
   and line 58, about defects tied to "a particular tool version"; neither is a rule for pinning a configuration
   version in a characterization test.

## Expected Behavior

A shared test helper (e.g. `expectVersionAtLeast(file, version, { historyNames: taskId })`) asserts "at least the
version this task wrote, and the history entry naming this task stays in the header", and the `testing` directive
carries one line saying that a live-configuration test pins a version only that way.

## Actual Behavior

Exact pins written by default and loosened after they break.
