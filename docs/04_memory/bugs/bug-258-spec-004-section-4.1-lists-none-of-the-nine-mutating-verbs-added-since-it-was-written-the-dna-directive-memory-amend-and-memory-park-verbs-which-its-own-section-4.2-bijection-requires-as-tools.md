## Summary

`spec-004-mcp-surface-contract` §4.1 maps CLI verbs to Tool names for the eight verbs it was written with
(`memory add/submit/approve/reject/deprecate`, `workflow start/end/next`), and §4.2 requires a closed bijection
between the state-mutating CLI verbs and the Tools. Nine mutating operations shipped since are in neither
section: `dna add`, `dna remove`, `dna set`, `dna update`, `directive create`, `directive assign`,
`directive remove`, `memory amend`, `memory park`. `task-187`'s parity gate finds all nine and allowlists them
as `UNTRIAGED`.

   eight-row table; §4.2 says the Memory pillar's mutating verbs are "exactly the five lifecycle verbs".

   memoryDeprecate memoryPark memoryAmend directiveCreate directiveAssign directiveRemove`.
3. `npx jest test/docs/mcp-surface-parity.test.ts` → passes, warning "20 allowlisted finding(s), 9 untriaged",
   the nine `missing` items above.

   `spec-005` §Context's missing `directives` noun.

§4.1 names a Tool for every state-mutating verb `CORE_MODULES` derives (or states why a verb has none), §4.2's
