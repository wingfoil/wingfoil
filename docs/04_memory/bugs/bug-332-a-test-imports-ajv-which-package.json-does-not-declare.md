## Summary

`test/release-health/measure.test.ts` validates reports with `ajv/dist/2020`, but `ajv` is not a dependency
of `package.json`: it resolves only because `@modelcontextprotocol/sdk` brings `ajv@8` and npm hoists it, while
`eslint` brings `ajv@6`, which has no `dist/2020`.

## Steps to Reproduce

On `main` at `29b8406a`, after `npm ci`:

1. `grep -n "ajv" test/release-health/measure.test.ts | head -1` → `21:import Ajv2020 from 'ajv/dist/2020';`.
2. `grep -c '"ajv"' package.json` → `0`.
3. `npm ls ajv` → `@modelcontextprotocol/sdk@1.32.0` → `ajv@8.20.0`, and `eslint@10.6.0` → `ajv@6.15.0`;
   `node -e "console.log(require('ajv/package.json').version)"` → `8.20.0` (the hoisted copy).

## Expected Behavior

`ajv` is a declared `devDependency` (pinned to the major the test uses), so the test does not depend on
another package's dependency tree or on hoisting order; or the test validates without it.

## Actual Behavior

As in steps 1–3.
