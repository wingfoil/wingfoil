## Summary

The control-character gate `task-173` added (`test/lint/control-characters.test.ts`, `bug-073`) fails on a
tracked text file holding a byte in `[\x00-\x08\x0b\x0c\x0e-\x1f\x7f]`, exactly as its AC defined it
(`isControlByte`, `test/lint/helpers/control-characters.ts:31-35`). It judges single bytes, so every character
whose UTF-8 encoding is multi-byte passes: the C1 controls (U+0080 to U+009F), NO-BREAK SPACE (U+00A0), the line
and paragraph separators (U+2028, U+2029), the zero-width characters (U+200B to U+200F, U+FEFF) and the
bidirectional controls (U+202A to U+202E, U+2066 to U+2069). The last group is the "Trojan Source" class GitHub
warns about: text that renders in a different order than the compiler or a reviewer's tool reads it. The gate
let five such characters into `task-173`'s own test file; the independent review caught them by eye.

## Steps to Reproduce

On `main` at `d3724884`:

1. `sed -n 31,35p test/lint/helpers/control-characters.ts` → the byte rule: DEL, or below 0x20 except tab, LF
   and CR.
2. `git show 7a72158e^:test/memory/reason-trailer.test.ts | grep -cP '[\x{2028}\x{2029}\x{00A0}\x{2027}\x{202A}]'`
   → `5` (raw U+2028, U+2029, NBSP, U+2027 and the bidi control U+202A, on the commit before `task-173`'s review
   fix), while `git show 7a72158e^:test/lint/control-characters.test.ts` shows the gate already in place.
   `7a72158e` rewrote them as escapes.
3. `git grep -lP '[\x{0080}-\x{00A0}\x{2027}-\x{202E}\x{2066}-\x{2069}\x{200B}-\x{200F}\x{FEFF}]'` → only the five
   PNG files under `docs/assets/`: no tracked text file holds one today, so widening the gate costs no cleanup.

## Expected Behavior

The gate (or a sibling rule in the same suite) also refuses, in tracked text files, the bidi controls and the
invisible or line-breaking code points listed above, naming the file, line and code point, with a declared,
versioned allow-list for any file that must hold one raw (none does today). Tests that need such a character
write it as an escape, as `7a72158e` did.

## Actual Behavior

Only C0 and DEL are caught; an editing tool that turns a typed `\uXXXX` escape into the character itself (the
cause of both `bug-073` and the five characters above) goes unnoticed unless a reviewer looks.
