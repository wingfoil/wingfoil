`spec-007` §2's `generic-api-key-assignment` rule (`src/validation/secret-scan.ts:48-54`, severity `block`)
matches `secret`, `token`, `password`, `passwd` or `api key` followed by `:` or `=` and any 16 characters of
`[A-Za-z0-9_\-/+=]`, case-insensitively and with no word boundary. An ordinary English sentence whose colon
follows one of those words and precedes a hyphenated name of 16 characters or more matches. The repository's
own REQ-SEC-08 gate (`test/validation/secret-scan.test.ts`, "matches 0 blocking secret patterns across this
repository's indexed surface", over `.wingfoil/` and `docs/04_memory/`) then fails the suite on prose.

to choose: require a word boundary before the key word and a value with at least one digit or upper-case letter
(real keys are not lower-case hyphenated words); or exempt values made only of lower-case words joined by
