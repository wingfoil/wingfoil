## Summary

`memory.yaml` accepts a type `path` pattern with literal `..` segments when it is loaded (`src/memory/schema.ts:195`,
`path: z.string()`). A pattern that stays inside the repository root then writes documents to the folder the `..`
segments resolve to, outside the folder the pattern spells, and the type-folder check `task-281` added
(`E_PATH_OUTSIDE_TYPE_FOLDER`) does not catch it; a pattern that leaves the root fails with a raw git error, not a
schema error.

## Steps to Reproduce

With the build of `main` at `bd55f70e`, in a scratch repository (`git init`, a git identity) holding a copy of this
repository's `.wingfoil/`:

1. Set the `bug` type's path to `docs/04_memory/bugs/../../outside/{id}.md` and commit.
2. `node <build>/dist/cli.js memory search --type bug` → exit 0: the configuration loads.
3. `node <build>/dist/cli.js memory add --type bug --title probe` → exit 0, `"path": "docs/outside/bug-001-probe.md"`,
   committed as `wf(bug): add bug-001-probe`: the document lands in `docs/outside/`, not under
   `docs/04_memory/bugs/`.
4. Set the path to `../escaped/{id}.md` and commit; `memory search --type bug` still exits 0, and `memory add --type
   bug --title "probe two"` → `error: E_GIT_READ_FAILED: git ls-files -z --cached --others --exclude-standard --
   ../escaped/ failed … '../escaped/' is outside repository`, exit 1.
5. `sed -n 151,177p src/storage/memory-path.ts`: `resolveConfinedMemoryPath` compares the normalized path with
   `pathPatternFolder(pattern)`, the folder of the pattern itself, so a `..` in the pattern moves both sides alike;
   only `..` in a token value is refused (`task-281`, `bug-325`).

## Expected Behavior

The schema refuses an absolute path or a `.`/`..` segment in a type's `path` when `memory.yaml` is loaded, as
`parseSetOptions` refuses them in a token value since `task-281` (approver ruling D3 of 2026-10-12), with a
validation error naming the type and the pattern.

## Actual Behavior

The pattern loads; inside the root it writes where the `..` leads, outside the root it fails late with a git error.
