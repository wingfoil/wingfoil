## Summary

`test/storage/git-root.test.ts` builds its "outside any repository" fixtures with `mkdtempSync(join(tmpdir(), 'wf-no-git-'))`
(lines 33 and 63) and assumes no ancestor of the OS temp directory holds a `.git`; an empty `/tmp/.git` on the host made
`findGitRoot` return `/tmp`, and 2 of its 6 tests failed in every full run.

## Steps to Reproduce

1. On `release/0.3` (`13c019509`), `mkdir /tmp/.git` (an empty directory is enough).
2. `npx jest test/storage/git-root.test.ts --maxWorkers=1` → `Tests: 2 failed, 4 passed, 6 total`: "returns null when no ancestor
   directory contains .git" received `"/tmp"`, and "throws E_NO_GIT_ROOT" received `E_NOT_AT_GIT_ROOT`.
3. `rmdir /tmp/.git` → the same command prints `Tests: 6 passed, 6 total`.

## Expected Behavior

Every suite with an "outside any repository" fixture (this one, `test/cli/integration-branch.test.ts`) gives the same result whatever
sits above the OS temp directory: its no-repository fixture stops the upward search
itself (for example `GIT_CEILING_DIRECTORIES`, or a parameter of `findGitRoot`'s test seam), so a `.git` in `/tmp` or in any
ancestor cannot reach it.

## Actual Behavior

The fixture is a plain temp directory; `findGitRoot` walks up past it and stops at the first `.git` it finds.
