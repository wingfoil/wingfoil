## Summary

`scripts/changelog-section.cjs` as `task-363` leaves it (head `d4baef9c7`) has two option gaps and one parsing edge:
`--lines` silently accepts and ignores `--changelog`; `--check --repo <dir>` reads the script's own `CHANGELOG.md`, not
`<dir>/CHANGELOG.md`; and the heading scan treats every line that starts with `#` as a heading, so a `#` line inside a
fenced code block, or a sub-heading under `### Breaking` or `### Deprecated`, is read as a heading of the section.

## Steps to Reproduce

From the `task-363` worktree at `d4baef9c7`, with a scratch directory `$d`:

1. `node scripts/changelog-section.cjs 0.4.0 --lines --changelog /nonexistent` → exit 0, the two lines, no word about
   the ignored option.
2. `node scripts/changelog-section.cjs 0.4.0 --check --repo $d`, where `$d` holds no `CHANGELOG.md` → exit 1, `error: no
   section `## [0.4.0]` in the changelog`: the script read its own repository's `CHANGELOG.md` (which has no 0.4.0
   section yet), not `$d/CHANGELOG.md`, which does not exist.
3. A 0.4.0 section whose two lines are correct, then `### Breaking`, `#### Sub`, `- item` →
   `--check --changelog <that file>` → exit 1, `error: "### Breaking" has no item`.
4. A 0.4.0 section whose two lines are correct, then `### Added`, a fenced block holding the line `### Breaking`, then
   `- item` → `--check --changelog <that file>` → exit 1, `error: "### Breaking" is not the first "###" heading`.

## Expected Behavior

- `--lines` refuses `--changelog` as a usage error (exit 2), or the usage line documents that `--lines` ignores it.
- `--check --repo <dir>` reads `<dir>/CHANGELOG.md` unless `--changelog` names another file, as `--lines` reads the
  fixture and the baseline from `<dir>`.
- Lines inside a fenced code block are never headings; a deeper heading (`####`) under `### Breaking` or
  `### Deprecated` stays part of that block, so its items count.

## Actual Behavior

As in the steps: exit 0 with the option ignored; the wrong `CHANGELOG.md` read; a sub-heading leaving `### Breaking`
with "no item"; a fenced `### Breaking` reported as a real heading.
