# dna update --entry-<field> rewrites a flow list without the spaces inside its brackets

## Summary

`wingfoil dna update <collection>.<entry> --entry-<field> a,b,…` on a field written as a spaced flow list
(`[ a, b ]`) writes the new list unspaced (`[a, b, c]`). The edit is minimal in every other way, and the content is
right; only the bracket spacing changes. The entry-field path builds one `set-scalar` edit per field
(`entryFieldEdit`, `src/dna/mutate.ts`), and `editSetScalar` renders the value with `renderInline`, which is `js-yaml`'s
own flow form. The `replace-list` path, by contrast, goes through `rewriteFlow`, which copies the bracket spacing of the
line it replaces (`renderFlow(items, spaced)`, `src/dna/edit.ts`, at `02ffe01ca`).

## Expected Behavior

An entry field that holds a flow list keeps the bracket spacing of the line it replaces, as `editReplaceList` already
does: `executes_as: [ developer, reviewer, qa, architect, facilitator, coordinator ]`.

## Actual Behavior

The line is rewritten in `js-yaml`'s unspaced flow form, so the diff of a one-item change touches the spacing too and a
hand-aligned file drifts away from its own style.
