## Summary

`scripts/e2e-smoke.cjs` runs `npm pack` and `npm install` (its candidate driver, lines 990 and 994, through `must`, line 977)
with the caller's environment, so any `npm_config_*` the caller exports reaches them: an inherited `npm_config_dry_run=true`
makes `npm pack` print the tarball name and exit 0 while writing no file, and the smoke then installs a tarball that does not
exist.

## Steps to Reproduce

1. In a checkout of `release/0.3` (`934c2e020`), make an empty directory `<out>`.
2. `npm_config_dry_run=true npm pack --silent --ignore-scripts --pack-destination <out>` → prints `wingfoil-0.3.1.tgz`,
   exit 0; `ls <out> | wc -l` → `0`.
3. The same command without `npm_config_dry_run` → prints `wingfoil-0.3.1.tgz`, `ls <out> | wc -l` → `1`.
   (`--ignore-scripts` only skips the build in this reproduction; the smoke's call is
   `npm pack --silent --pack-destination <dir>` and reads the same configuration.)

## Expected Behavior

The smoke's npm calls run with the caller's `npm_config_*` removed (the same rule `bug-209` set for the test suites,
`withoutCallerNpmConfig` in `test/cli/helpers/npm-env.ts`), plus what the smoke sets on purpose, so the candidate it installs
is the one it packed whatever the caller's npm environment.

## Actual Behavior

`must` (`scripts/e2e-smoke.cjs:977`) calls `spawnSync(command, args, { cwd, encoding, stdio })` with no `env`, so the npm
children inherit every `npm_config_*` of the caller; `test/lint/npm-caller-config.test.ts` (task-316) checks only the
spawns under `test/`.
