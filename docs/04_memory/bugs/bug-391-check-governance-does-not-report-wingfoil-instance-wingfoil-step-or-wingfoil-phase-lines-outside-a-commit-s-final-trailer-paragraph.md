## Summary

`scripts/check-governance.cjs` reports a `WingFoil-Version:` line read into a `Reason:` block, but has no rule for the
workflow-link trailers: a hand amend that adds the attribution as a separate paragraph to a commit carrying
`WingFoil-Instance:` / `WingFoil-Step:` (a `memory add --workflow … --step …`) or `WingFoil-Phase:` (a `workflow
finalize` record) moves them out of the final paragraph, unlinks the element from its step or erases the record, and
the governance check passes.

## Steps to Reproduce

On `main` at `39d4a6f6`:

1. `grep -n "WingFoil-Instance\|WingFoil-Step\|WingFoil-Phase" scripts/check-governance.cjs` → no match (exit 1); the
   positive case of the reader: `grep -n "WingFoil-Instance" src/core/workflow-deduction.ts` → line 213, and the
   deduction reads `%(trailers:only,unfold)` (line 137), git's final-paragraph trailers only.
2. Hence the shape `git-conventions` §8 forbids — `git commit --amend -m "$(git log -1 --format=%B)" -m
   "Co-Authored-By: …"` on a commit `memory add --workflow … --step …` wrote, which puts the attribution in a new
   final paragraph — is not reported by any rule of the check (not reproduced end to end here; step 1 is the
   evidence that no rule names these trailers).

## Expected Behavior

The governance check reports a `wf(…)` commit, or a `workflow: finalize` record, whose body carries a
`WingFoil-Instance:`, `WingFoil-Step:`, `WingFoil-Phase:`, `WingFoil-Element:` or `WingFoil-Item:` line outside the
commit's final paragraph, as it already reports a `WingFoil-Version:` line inside a reason.

## Actual Behavior

No rule exists; the documents (`git-conventions` 1.9 §8, the agent file's §5.1) state the `--trailer` rule, and
nothing checks it.
