## Summary

Two workflow declarations that cannot work as meant load with `diagnostics []` and run with no word about them:

1. A `produces` entry naming a directory without the trailing `/` (`docs/out`) is read as a file (spec-017 §4.3: only a
   pattern ending in `/` matches a committed file under it), so it is never satisfied, `workflow finalize` refuses the
   step because it "completes from its evidence", and `workflow end` refuses the run: the only way out is to deprecate
   the plan.
2. A phase whose role no `team.members` entry holds and no `team.agents` entry executes as runs normally;
   `workflow next` prints the role alone. For an approval role the same gap is reported (`no approver found for role
   …`, spec-017 §5.1).

Both reproduced on 0.3.2.
