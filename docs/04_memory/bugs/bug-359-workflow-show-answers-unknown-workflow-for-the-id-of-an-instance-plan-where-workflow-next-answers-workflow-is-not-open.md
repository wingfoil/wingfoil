## Summary

`wingfoil workflow show <id>` answers `unknown workflow: <id>` for the id of an instance plan that exists at `HEAD`,
while `workflow next <id>` answers `workflow is not open: <id>` for the same id, so the user is told the id names
nothing although it names a (closed) instance.

On `main` at `bd55f70e`, with the instance plan `bug-ingest-rel-v0.3-w3b6-review-findings-plan` (`type: plan`,
`parent: ""`, `status: done`):

1. `node dist/cli.js workflow show bug-ingest-rel-v0.3-w3b6-review-findings-plan` → `error: unknown workflow:
   bug-ingest-rel-v0.3-w3b6-review-findings-plan`, exit 1.
2. `node dist/cli.js workflow next bug-ingest-rel-v0.3-w3b6-review-findings-plan` → `error: workflow is not open:

   instance plan that is not open to `next`, `status`, `finalize`, `end` and `memory add --workflow` only.

## Expected Behavior

One answer for an instance plan's id across the workflow commands: `show` recognises an instance plan id and says so
(for example that it is an instance of workflow `bug-ingest`, which `show` takes by name), or §7.6 and §10 state that
`show` takes names only and its message says the id is not a workflow name.

## Actual Behavior

`show` reports a closed instance's id as an unknown workflow; `next` reports it as not open.
