## Summary

In `wingfoil@0.3.0`, `workflow finalize <instance> --dry-run` without `--format json` exits 1 with `error: Cannot read
properties of undefined (reading 'workflow')` and prints no plan. The console renderer receives the dry-run commit plan
in place of a finalize result. `task-295` fixed it, together with the same defect in `workflow adopt` and `workflow
rekey`, which no release ever shipped with. The fix was released in `wingfoil@0.3.1`.

## Steps to Reproduce

With the 0.3.0 build: on `release/0.3` before `patch-v0.3.2`'s pin advance, `node_modules/wingfoil-released/dist/cli.js`
is 0.3.0 (`npm run -s wingfoil -- --version` → `0.3.0 (cc31d7a8…)`). Otherwise, `npm install --prefix <tmp>
wingfoil@0.3.0`. Call it `$WF0`.

1. `git init -b main <scratch> && cd <scratch> && git config user.name "Scratch" && git config user.email
   scratch@example.invalid`
2. `node $WF0 init --template Scrum`
3. `node $WF0 workflow start bug-ingest` → `started bug-ingest as bug-ingest-1-plan (active)`; `node $WF0 workflow
   next` → `next step: bug-ingest.capture`, `evidence missing: record (finalizable)`.
4. `node $WF0 workflow finalize bug-ingest-1-plan --dry-run; echo "exit=$?"`
5. `node $WF0 workflow finalize bug-ingest-1-plan --dry-run --format json; echo "exit=$?"`

## Expected Behavior

Step 4 exits 0 and prints the plan (`dryRun: true`, the subject `workflow: finalize bug-ingest-1-plan
bug-ingest.capture`, `paths: []`, `diff: ""`), as `workflow start --dry-run` prints its plan in the console format,
and writes nothing.

## Actual Behavior

Run on 2026-10-27 in a scratch repository with the 0.3.0 build above:
- Step 4: `error: Cannot read properties of undefined (reading 'workflow')`, `exit=1`.
- Step 5: the JSON plan, `exit=0`. So the command is not refused: only the console rendering fails.
- Nothing was written: `git status --porcelain` was empty, and `HEAD` was unchanged (`11ccb8a2`).

With the build of `release/0.3` at `8e7fc43b` (`node dist/cli.js --version` → `0.3.1 (8e7fc43b…)`), step 4 prints the
plan as indented JSON and exits 0.
