## Summary

`memoryUnreadableDiagnostic` (`src/memory/query.ts`) is the one builder of `W_MEMORY_UNREADABLE`, and its
message is `spec-017` §1.4's literal `unreadable frontmatter in <file>: <reason>`. §1.4 defines the code for a
document "whose frontmatter does not parse", but five kinds of left-out document now share it, and for four of
them the frontmatter is not what failed: a document in a newer format (`task-257`), a symbolic link (`task-171`), and, in
an execution context (`task-255`), a document with no string `type`/`id` and one whose body holds its own end
marker. Each warning's lead says "unreadable frontmatter" and only its reason says what happened.
