## Summary
The built-in agent adapters `init` writes, `.wingfoil/agents/built-in/claude-code.yaml` and `codex-cli.yaml`, open with a comment naming
WingFoil's own ids: `# Claude Code, a built-in adapter (spec-016 section 2.8)` and, on the next line, `(task-236)`. A project that uses
WingFoil has no `spec-016` or `task-236`. The six built-in directives also carry `ref: [P3.8]` in their frontmatter, WingFoil's own
feature id, a field `src/storage/builtin-directives.ts` declares on purpose.

   both adapters (`spec-016`, `task-236`) and line 8 (`ref: [P3.8]`) of the six directives.

## Expected Behavior
The comments of the built-in assets `init` writes name no WingFoil-internal id (the same rule `task-321` applied to the configuration
files, after `bug-409`); whether the directives' `ref:` field should name a WingFoil feature id in a user's project is decided at triage
