## Summary

`npm audit --omit=dev` on this repository reports 6 advisories in the production dependency tree (3 high,
3 moderate), all transitive through `@modelcontextprotocol/sdk@1.29.0` except `js-yaml@4.3.0`, a direct
dependency. They come from `package-lock.json`, which still pins the vulnerable versions. A fresh install of the
published `wingfoil@0.2.2` resolves none of them today, because `package.json`'s caret ranges admit the
fixed releases; but the same ranges also admit the vulnerable ones, so a consumer lock made earlier keeps them,
and this repository's CI, tests and release build run on them. The local OpenSSF Scorecard run of 2026-10-05
(`ghcr.io/ossf/scorecard:v5.5.0`, pushed head `ea637c43`) scored Vulnerabilities 0 with 38 OSV advisories.
