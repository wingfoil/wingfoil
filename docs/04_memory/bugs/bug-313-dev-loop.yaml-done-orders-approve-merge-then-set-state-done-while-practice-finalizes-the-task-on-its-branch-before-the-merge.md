## Summary

`dev-loop.yaml`'s `done` phase orders `memory.approve` → `git.merge(to: main, ff: false)` → `git.remove_worktree` →
`element.set_state(done)`, so the task would be finalized on `main` after the merge; in practice the approve and the
finalize are committed on `task/<id>` and the merge carries them, so the declared order and the history disagree.
