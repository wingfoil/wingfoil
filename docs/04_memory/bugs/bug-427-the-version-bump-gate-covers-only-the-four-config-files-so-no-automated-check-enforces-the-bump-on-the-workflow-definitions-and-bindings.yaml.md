## Summary

`test/lint/version-bump.test.ts` and the governance check's `config-version` rule judge only `VERSIONED_CONFIG_FILES`
— `.wingfoil/dna.yaml`, `memory.yaml`, `workflows.yaml`, `roles.yaml` — although every workflow definition under
`.wingfoil/workflows/custom/` and `.wingfoil/workflows/bindings.yaml` declares a `version:` the `doc-versioning` bump
rule applies to. An edit of one of those files without its bump passes `npm test` and `npm run check:governance`; the
rule is enforced for them only at review.

## Steps to Reproduce

From the repository root:

1. `sed -n 32,38p test/lint/helpers/version-bump.ts` — `VERSIONED_CONFIG_FILES` lists the four files; `sed -n 74,80p
   test/lint/version-bump.test.ts` pins that list ("judges exactly the four versioned config files").
2. `grep -n "^const VERSIONED_CONFIG_FILES" scripts/check-governance.cjs` (line 129) — the same four for `config-version`.
3. `grep -c "^version:" .wingfoil/workflows/custom/*.yaml .wingfoil/workflows/bindings.yaml | grep -c ':1$'` → `28`:
   all 27 workflow files and `bindings.yaml` declare a `version:` (e.g. `dev-loop.yaml` `version: 2.2`,
   `bindings.yaml` `version: 2.6`).
4. `sed -n 18,19p .wingfoil/directives/custom/doc-versioning.md` — "The bump rule applies where a document declares a
   version"; `sed -n 47p` — the Gate is declared for "the four versioned config files only".
5. In a throw-away worktree, change a comment in `.wingfoil/workflows/custom/bug-ingest.yaml` without touching its
   `version:` and run `npx jest test/lint/version-bump.test.ts --maxWorkers=2` → it passes (not run for this bug: the
   result follows from steps 1–2, which never read the file).

## Expected Behavior

Every `.wingfoil/` configuration file that declares a `version:` is held to the once-per-branch bump by the same gate
(the pending-change test and `config-version` over a range), or the directive states why a file is exempt.

## Actual Behavior

Only the four files are gated; a content edit of a workflow definition or of the bindings file that skips its bump is
caught only if a reviewer notices it.
