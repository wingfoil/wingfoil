## Summary

`memory search --type <t>` with a type `.wingfoil/memory.yaml` does not declare exits 0 and answers that no documents matched,
while the MCP Resource `wingfoil://memory/<t>` refuses the same undeclared type as not found.

## Steps to Reproduce

1. In an empty git repository, `node <release/0.3 checkout>/dist/cli.js init --template scrum` (code build `0.3.1 (13c01950…)`).
2. `wingfoil memory search --type nosuch` → exit 0, prints `{"query": "", "matches": [], "message": "no documents matched the query"}`.
3. `wingfoil --format json memory search --type nosuch` → exit 0, the same object.

## Expected Behavior

An undeclared `--type` is refused as a usage error that names the declared types (spec-005's command-line refusal, exit 2), or at
least answered with a warning saying the type is not declared, so a typo in the type is not read as "nothing matched".

## Actual Behavior

`memorySearchFn` (`src/core/index.ts`) passes the type through as a filter; an undeclared type matches nothing and the command
succeeds.
