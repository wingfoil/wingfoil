## Summary

For a `<ref>` that names a plan element which is not open (a `done` instance), `workflow next` and `workflow
finalize` print `unknown workflow: <ref>`, while `workflow end` prints `workflow is not open: <ref>`, which is what
`spec-017` §10 declares for every `<ref>` that names no open instance.

## Steps to Reproduce

On `main` at `29b8406a`, with `npm run build` done:

1. `node dist/cli.js workflow next bug-ingest-rel-v0.3-w3b4-review-findings-plan` → `error: unknown workflow:
   bug-ingest-rel-v0.3-w3b4-review-findings-plan`, exit 1 (the plan is `done`).
2. `node dist/cli.js workflow finalize bug-ingest-rel-v0.3-w3b4-review-findings-plan --dry-run` → the same `unknown
   workflow` message, exit 1.
3. `node dist/cli.js workflow end bug-ingest-rel-v0.3-w3b4-review-findings-plan --dry-run` → `error: workflow is not
   open: bug-ingest-rel-v0.3-w3b4-review-findings-plan`, exit 1.
4. `grep -n "names no open instance" docs/04_memory/design/specs/spec-017-workflow-commands-and-state-deduction.md` →
   the §10 row "`<ref>` names no open instance … | `workflow is not open: <ref>` | `NOT_FOUND` | 1"; the row for
   `unknown workflow` covers an unknown workflow **name**.
5. `sed -n 519,526p src/core/workflow-next.ts`: the shared resolver answers `workflow is not open` only when `<ref>`
   equals a workflow name, and `unknown workflow` for any other `<ref>`, an instance id included.

## Expected Behavior

A `<ref>` that names a plan element of the instance kind (`parent` empty) which exists at `HEAD` but is not
open is answered `workflow is not open: <ref>` by `next` and `finalize`, as by `end`; `unknown workflow` is kept for a
`<ref>` that names neither a workflow nor a plan.

## Actual Behavior

As in steps 1–2.

## Notes

- Exit code and `CoreError.code` (`NOT_FOUND`) are already right; only the message differs, so a script that
  matches on it sees two answers for one case.
- Source: `task-217` design decision D5 and its independent review (W3 B5): "next vs end message inconsistency";
  `task-226` made `finalize` share the resolver.
