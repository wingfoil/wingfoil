## Summary

Every state-mutating command checks the git identity first (REQ-SEC-01, `requireGitIdentity`), and the check reads
it with one `git config` spawn whose every failure is swallowed into "no value": when `git` itself cannot be run
(the spawn fails with `ENOENT`, `EACCES` or `EPERM`), the command refuses with REQ-SEC-01's message, `git identity
not configured (user.name/user.email)`, and sends the user to fix a configuration that may be correct.

## Expected Behavior

- When `git` cannot be spawned, a distinct refusal names the real cause: `could not run git: <cause>`, the cause
  being the spawn error's code and message (for example `spawnSync git EPERM`), exit `1`, nothing written.
- REQ-SEC-01's exact message stays for the case it describes: git ran and `git config --get-regexp` found no
  matching key (its exit `1`; `git -C <fresh repository> config -z --get-regexp
  '^(author|committer|user)\.(name|email)$'` with `GIT_CONFIG_GLOBAL=/dev/null GIT_CONFIG_NOSYSTEM=1` → exit `1`, no
  output).

## Actual Behavior

Any failure of the spawn, including one where git never ran, is reported as `git identity not configured
(user.name/user.email)`, exit `1`. The user is told to set `user.name`/`user.email`, which does not help.

## Notes

- Requirement: REQ-SEC-01 (`docs/02_requirements/03_sard/05_security-compliance.md`, lines 10-16): its fit
  criterion fixes the message for "git identity unset"; it says nothing about a git that cannot be run, so the
  distinct message does not change the requirement.
- Other exits of `git config` (for example `128`, `fatal: cannot change to '<dir>'`, for a root git cannot enter) are
  outside this bug's ask; the fix task's design states which of them keep the identity message.
- Severity medium: the refusal is correct (nothing is written), but its message is wrong and points away from the
  cause; it hits every mutating command for any user whose agent sandbox blocks Node's process spawns.
- Related: `task-014` (the pre-flight), `task-132` (the single-spawn read), `adr-006`.
