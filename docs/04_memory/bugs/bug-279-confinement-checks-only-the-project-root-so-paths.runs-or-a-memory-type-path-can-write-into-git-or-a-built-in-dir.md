## Summary

The storage confinement of REQ-SEC-06 (`escapesRoot` and `resolveRealPathInRoot`, `src/storage/confinement.ts`;
`requireConfinedTarget`, `src/core/confinement.ts`) decides one thing: whether a path is strictly inside the project
root. Two writers take their target directory from configuration and are judged by that test alone, so a target
inside the root but in a place WingFoil should never write to passes:

- the run log: `resolveRunLogPath` (`src/agent/run-log.ts`) joins `dna.yaml` `paths.runs` with `<element-id>.jsonl`,
  and `paths.runs: [.git/]` resolves to `.git/<element-id>.jsonl` — inside git's own directory;
- a Memory type: `memory add` writes wherever the type's `memory.yaml` `path` pattern points, so a type whose path is
  `.wingfoil/agents/built-in/{id}.md` writes and commits a file into the built-in adapter directory, which REQ-SEC-07
  defines by location as the immutable built-in assets.

## Steps to Reproduce

On `main` at `0962f85f` (`npm ci && npm run build`), in scratch repositories made with `git init`, a local identity and
`node dist/cli.js init --template Scrum`:

1. `node -e "…require('./dist/agent/run-log.js').resolveRunLogPath(process.cwd(), ['.git/'], 'task-001')"` →
   `{"ok":true,"value":".git/task-001.jsonl"}`. The same call with `['/etc']` is refused (`… resolves to
   '/etc/task-001.jsonl', outside the project root …`), so the check runs and catches an escape.
2. With `paths: … runs: [.git/]` committed in `.wingfoil/dna.yaml`, `node dist/cli.js paths runs` → exit 0,
   `"paths": [".git/"]`: the configuration loads without complaint.
3. With the `bug` type's `path` changed to `.wingfoil/agents/built-in/{id}.md` in `.wingfoil/memory.yaml` and
   committed, `node dist/cli.js memory add --type bug --title probe` → exit 0, `"path":
   ".wingfoil/agents/built-in/bug-001-probe.md"`; `git log -1 --stat` → `wf(bug): add bug-001-probe`, one file,
   `.wingfoil/agents/built-in/bug-001-probe.md`. `node dist/cli.js workflow list` on that repository still exits 0.

## Expected Behavior

A writer whose target comes from configuration refuses a target inside the root that WingFoil does not own as that
kind of state: at least `.git/`, and the `built-in/` directories REQ-SEC-07 makes immutable (and arguably the rest
of `.wingfoil/`, which only the configuration writers touch). The refusal comes at load (`dna.yaml`/`memory.yaml`
validation) or at the write, with a WingFoil message naming the configured key, and nothing is written.

## Actual Behavior

Both targets pass confinement: the run-log path resolves into `.git/`, and `memory add` commits a document into
`.wingfoil/agents/built-in/`.
