## Summary

`scripts/check-governance.cjs` ends its console report with `gated: <n> findings on <m> commits`. Here `<m>` is the
number of distinct commits that have a finding, not the number of commits checked. A clean run therefore prints
`gated: 0 findings on 0 commits`, which reads as though nothing was checked. The `--json` report for the same range
gives `checked`, `gatedCommits` and `findings` separately. The `history:` and `state not checked:` lines use the same
count. Every gate log that quotes the summary carries the misleading line.

## Steps to Reproduce

From the repository root:

1. `node scripts/check-governance.cjs --base 22d72ab0`. On 2026-10-27 this printed:
   ```
   governance check: 4 wf() commits in 22d72ab025765b21ef28ea353985718906020b0d..HEAD (4 after the introduction commit fcd43569…), and 1 other commits
   …
   gated: 0 findings on 0 commits
   history: 0 findings on 0 commits
   state not checked: 0 entries on 0 commits (…)
   ```
2. `node scripts/check-governance.cjs --base 22d72ab0 --json`, reading `checked`, `gatedCommits`, `otherCommits` and
   `findings.length` → `{ checked: 4, gatedCommits: 4, otherCommits: 1, findings: 0 }`. A longer range shows the
   same pattern: `task-302`'s notes record "gated: 0 findings on 0 commits" beside `--json`'s `"checked": 163,
   "gatedCommits": 163, "findings": 0` (`grep -n "findings on" docs/04_memory/v0.3.1/task-302-*.md`).
3. `sed -n 970,975p scripts/check-governance.cjs` shows the cause:
   `const commitsWith = (findings) => new Set(findings.map((finding) => finding.sha)).size;`, used as the "on N
   commits" figure of all three lines.

## Expected Behavior

Each summary line says what its numbers count. For example: `gated: 0 findings (on 0 of 4 gated commits)`, or the
findings line drops the commit count and the first line keeps the number checked. The `--json` fields do not
change.

## Actual Behavior

`gated: 0 findings on 0 commits` on a clean range of 4 (or 163) gated commits. The first line does give the count
checked, but the summary line seems to contradict it.
