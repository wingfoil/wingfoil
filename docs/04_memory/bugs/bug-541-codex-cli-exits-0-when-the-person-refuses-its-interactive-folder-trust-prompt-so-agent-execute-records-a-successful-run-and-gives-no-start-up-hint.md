# codex-cli exits 0 when the person refuses its interactive folder trust prompt so agent execute records a successful run and gives no start-up hint

## Summary

`task-353` gives the start-up hint (`spec-016` §3.3 step 16, as amended at its design gate) only when a run under
`launch.<kind>.trust: prompt` ends unsuccessfully with no commit since `state_ref`. In a directory it has not seen,
`codex` asks whether to trust the folder. If the person refuses, `codex-cli 0.167.2` exits `0`, so `agent execute`
records the interactive run as a success and gives no hint. `claude` exits `1` after "No, exit", so the hint works for
`claude-code`. `bug-500`'s interactive case therefore stays open for `codex-cli`.

## Steps to Reproduce

1. `cd "$(mktemp -d)" && git init -q`.
2. Run `codex`, refuse the folder trust prompt and exit.
3. `echo $?` prints `0` (the approver's by-hand pass of 2026-11-14 on `codex-cli 0.167.2`; `claude` on
   `2.1.322 (Claude Code)` printed `1` after "No, exit").
4. Run `agent execute --interactive` with the `codex-cli` built-in in a project `codex` has not trusted, and refuse the
   prompt. The run is recorded with exit status `0` and `notes` `none`, and no `warning:` line is printed.

## Expected Behavior

An interactive run that stopped at the agent CLI's trust prompt is told apart from a successful one. For example, the
hint may also be given when a run under `trust: prompt` exits `0` with no commit since `state_ref` (a design change to
`spec-016` §3.3 step 16). Alternatively, `codex-cli`'s built-in declares an argv fragment that trusts the launch
directory, once its CLI has one (§2.8).

## Actual Behavior

The run is recorded as successful and nothing tells the person that the agent never started its work.

## Notes

Found at `task-353`'s review (finding F2, follow-up). The approver checked the exit statuses by hand, then ruled to
approve `task-353` as is and file this bug. Severity low, the approver's call: in an interactive launch the person at
the terminal saw the prompt and refused it themselves, and headless launches of both built-ins are `implied`.
