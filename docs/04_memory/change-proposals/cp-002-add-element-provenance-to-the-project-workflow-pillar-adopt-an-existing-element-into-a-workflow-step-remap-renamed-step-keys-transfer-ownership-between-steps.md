## The change

A new feature of the Project Workflow pillar, **P4.21 Element provenance**: record which workflow step
an existing element counts as created by (`adopt`), remap step keys after a rename (`rekey`) and move
an element's ownership between steps (`transfer`), each with an explicit, audited commit that changes
neither the element nor history. The design is `dl-187`; why it is needed and in which order this
repository uses it is `dl-186`.

- **Personas and journeys:** Morgan (tech lead) in Journey 0b (migrating an existing project) and
  Journey 6 (restructuring a workflow while work is in flight: "in-flight tasks may need manual
  migration"); Alex in Journey 0b. Also this repository, whose whole history predates the engine.
- **The row** it adds to `docs/01_vision/06_features.md`: P4.21, "Element provenance", journeys 0b and 6,
  personas Morgan and Alex, "Adopt an existing element into the workflow step that counts as having
  created it, remap renamed step keys and transfer ownership between steps, each as an audited commit",
  type Command.
