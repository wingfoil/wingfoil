P4 — the release workflows. v0.3.1 was the first patch run on a maintenance line, and its follow-ups showed what the
line's workflows do not yet declare: how a patch takes an element filed on `main`, the pin and the status line on a
patch line, the merge forward after the tag, the npm tarball wait, and how release-health settles a patch's
proposals. v0.3.2 runs those phases itself, so `w0` fixes them before they run. The rest is the low/medium backlog
v0.3 left, taken while it is cheap and before v0.4 changes the engine.
