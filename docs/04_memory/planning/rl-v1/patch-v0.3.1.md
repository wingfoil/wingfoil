## Pillar Focus

**Pillar 4 (Project Workflow).** The workflow engine shipped in 0.3.0 deduces state from evidence
but cannot see what was made before it, or by hand: element provenance gives it that evidence, and
the preparation of S3-b makes WingFoil's own Memory readable by it. The patch matters less for the
commands it adds than for what it unblocks: at v0.4, WingFoil's own development runs on its own
engine (`dl-186` S4).
