## Description

Feature **P5.1** (CLI). `dl-198` (`ready`, `42dcd8f52`) ratifies (a) with (c)'s documentation: a global
`--project <dir>` option names the root explicitly, and the user guide explains why the root is not inferred, because
v0.4's headless launches and the MCP server need a declared working root. Without the option, `E_NOT_AT_GIT_ROOT`
keeps applying (commands still do not resolve the root upwards from a subdirectory: option (b) was not taken).
`bug-406` and `bug-453`: the `findGitRoot` / git-root tests find a git repository above their temporary directory, so
a stray `.git` outside the project turns them red.
