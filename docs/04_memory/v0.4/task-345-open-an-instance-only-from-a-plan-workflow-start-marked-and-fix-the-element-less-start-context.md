## Description

Features **P4.2** (`workflow start`) and **P4.13** (deduction). `dl-217` (a) (`ready`, `ae1d54d62`): a plan is an open
instance only when `workflow start` wrote it — marked by an instance marker that `start` writes — and it names a loaded
startable workflow; a plan added by `memory add` is never an instance, a plan naming an unloaded workflow is ignored
for the active context and reported by `workflow list` as a warning, and the instances already open are kept.
`bug-413` (approver ruling at the v0.4 planning: option (c)): `workflow start` of an element-less main records the
active instance's element as its context even when unrelated, and nothing clears it. `bug-465`:
`selectWorkflowInstance` takes the snapshot as an optional argument, so a call without it still answers "workflow is
not open" for an unknown workflow.
