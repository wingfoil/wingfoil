## Description

Feature **P5.3.1**. `dl-188` part 1 (c) (`ready`, `d12ae928f`): a `claude-code` run record carries its token counts,
read first from the agent's local session transcript and, once `dl-183`'s headless launch exists and its JSON is
verified to carry usage, from the headless output. `dl-180` version (b) (`ready`, `74d9c65d2`): the agent CLI's version
is read before and after the run, both recorded, a difference flagged in the record and as a warning — closing
`bug-366` (a CLI that updates itself mid-session is recorded at the wrong version). `dl-181` Q1 (a): a work run's
`result` is `n/a`.
