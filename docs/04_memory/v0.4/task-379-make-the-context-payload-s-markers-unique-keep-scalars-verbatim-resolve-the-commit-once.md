## Description

Feature **P5.4.3**, REQ-SYS-07. Three defects of the context payload. `bug-265`: its body markers are not unique. `bug-267`: it rewrites
non-date scalars of the carried frontmatter. `bug-381`: the execution context re-resolves its commit in every loader and reads each directive
body with its own git spawn.

## Acceptance Criteria

1. (red-first) Every marker key in a payload is unique: a document whose frontmatter `type` is not the type its path declares, or whose
   `type:id` repeats one already carried, is left out and reported, or the key is unique by construction (`bug-265`).
2. (red-first) Every scalar is carried as written, or `spec-012` §7 states that only timestamps are kept; a test pins the choice made at the
   design gate (`bug-267`).
3. (red-first) The context is assembled at one resolved commit, with the directive bodies in one batched read, and a test counts the git
   spawns (`bug-381`).
