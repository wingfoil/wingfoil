## Description

Feature **P1.2**, REQ-SEC-02. Rule gaps of the governance check. `bug-319`: five gaps (non-`wf()` deletions, `supersedes-pair` judged at

3. (red-first) A `sync` citation must resolve to a `reject` of the element the sync mirrors (`bug-319` item 3).
4. (red-first) The pre-push hook checks every pushed ref, whatever `HEAD` is (`bug-319` item 4).
5. (red-first) The claim lint reads only the Execution Notes sections of the Memory documents the range changed (`bug-319` item 5).
6. (red-first) A `wf()` subject naming an id that is not the full id of a document the commit changes is reported, with the commit and the
   expected id (`bug-458`).
7. (red-first) Every commit that carries an `Approver:` line is held to the grammar and the authority rule (`bug-467` part 1).
8. (red-first) A record of an `approval:` phase with no `Approver:` line is a finding, or the rule states why not; the design gate rules which
   (`bug-467` part 2).
