## Description

Feature **P5.3.1** (the `agent` module's place in the architecture). `bug-345` (medium): `src` holds two import cycles
and six surface imports bypassing `src/core` that no element records. `bug-317`: the `src/core`–`src/agent` cycle
leaves module constants undefined by load order, and the `*AtRev` loaders label a file with the caller's rev string.
`bug-470`: loading `src/core/agent-execute` before the core barrel leaves `agentExecute` and `agentList` undefined in
`CORE_MODULES`. The `architecture` directive (bound to the architect at design) owns the module boundaries.

## Acceptance Criteria

1. (red-first) Every operation in `CORE_MODULES` has its `fn` whichever module of `src/core` is loaded first; a test
   loads each `dist/` module first, in turn, and checks `CORE_MODULES` and every exported constant (`bug-470`,
   `bug-317` Expected).
2. (red-first) No runtime import cycle remains in `src/`, and no surface module (`src/cli`, `src/mcp`) imports past
   `src/core` except where a Memory element records the deviation; a test enforces both (`bug-345` Expected;
   `architecture`).
3. (red-first) The `*AtRev` loaders take an optional `label` so the caller names the source, and `agent execute`'s
   rewrite of the label goes away (`bug-317`).
4. (characterization) `npm test` and `npm run typecheck` stay green; the public exports of `src/core/index.ts` are
   unchanged (`test/docs` API-docs gate).
