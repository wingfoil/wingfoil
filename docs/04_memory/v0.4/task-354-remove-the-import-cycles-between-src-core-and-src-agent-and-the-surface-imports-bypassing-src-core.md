## Description

Feature **P5.3.1** (the `agent` module's place in the architecture). `bug-345` (medium): `src` holds two import cycles
and six surface imports bypassing `src/core` that no element records. `bug-317`: the `src/core`–`src/agent` cycle
leaves module constants undefined by load order, and the `*AtRev` loaders label a file with the caller's rev string.
