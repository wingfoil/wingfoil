  `07292cfd`. Each task runs on its own `task/<id>` branch cut from `main` (`devloop-kit/start.sh`); the task's
  Memory commits go there, never on the phase branch. The phase branch merges the task branches after the
  approver's gate, then `main` with `--no-ff`. Check `git branch --show-current` before every commit.
- **Memory operations** run on the code build (`npm run build`, then `node dist/cli.js …`; `wingfoil-cli` §1),
  never the pinned one. Hand and tool commits carry the `git-conventions` §7 trailers (`Co-Authored-By: Claude
  <noreply@anthropic.com>`, `AI-Model: claude-opus-5-5`, added with `git commit --amend --no-edit --trailer` on a
  commit `wingfoil` wrote); `approve` and `reject` commits carry none. Reasons start with a verb (`dl-067`).
  `approve`/`reject`/push only on the approver's instruction.
- **Heavy gates** (`npm test`, `test:coverage`, the build's `tsc`) run one at a time behind
  `devloop-kit/waitslot.sh` (`dl-170` interim rule), with `--maxWorkers=2`, never detached, never `pkill -f`.
  High load from other projects is reported to the approver, their processes are not touched.
- **`doc-versioning`.** One bump per file per branch, baseline = the file's last commit on the integration
  branch (`main` for a minor); after `x.9` comes `(x+1).0`. Update the date with the bump.

  it, and the command was run; transcripts are pasted from real runs in a throwaway project.
- **Never** name the benchmark's hold-out repository or cite the private market-research repository (in
  `docs/comparison.md` and `docs/case-study.md` above all). Never touch `test/validation/secret-scan.test.ts`.
